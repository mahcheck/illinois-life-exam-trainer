How it works

1. Choose a topic and test size, then generate a test.
2. Choose Real Test Mode to hide correctness until the final score, or Practice Mode for instant feedback.
3. Tap an answer and confirm. In Practice Mode the card turns green for correct or red for incorrect, with an explanation.
4. Finish the test to save your score and review mistakes.
5. Generate another randomized test or visit Records to export/import attempts.

This practice bank contains original study questions. Generating new tests reshuffles this built-in bank; it does not use AI or download new questions. This is not an official Pearson VUE exam. For current state-specific requirements, consult the Illinois DOI and official Pearson VUE candidate outline.
